# AI-READONLY: 工作习惯

> AI 读取本文件以对齐你的工作节奏与习惯，避免在不合适的时间/方式打扰。

## 工作时段
- 高效专注时段：工作日白天为主（具体时段可随对话再沉淀）
- 不希望被打扰的时段：深夜休息时段优先不打扰
- 时区：Asia/Shanghai（UTC+8）

## 工作节奏偏好
- 正式材料先对齐口径与模板，再成稿；宁可多问一句也不写错口径
- 偏好把一件事做完再切下一件；长任务希望 AI 主动汇报进度
- 多 Agent 分工协作（公文、科技管理、数智、创新工作室、资料等）时，保持档案与口径一致
- 学习类任务（如看视频）完成后：关闭播放器并告知已看完

## 验收标准
- 代码/配置类任务：必须可执行、给出验证方式，不交付未经验证的猜测
- 文档/公文类任务：结论或主旨先行，层次与用语符合正式公文标准；关键数据仅用已确认公开口径
- 破坏性操作：任何删除/覆盖/对外发布前必须先确认

## 环境与平台
- 主力设备：Windows 桌面（主机名 DESKTOP-QDGO1D4）
- 主要工作目录：公司文件常用路径 `D:\工作`（仅作路径提示，不在此仓库存放公司内部文件）
- 沟通与触达：微信；Grok Bot 多 Agent 体系
