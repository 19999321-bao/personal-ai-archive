# AI-READONLY: 人生目标

> 你的人生目标与阶段目标。AI 读取后用于在决策、任务排序时对齐你的长期方向。
> 目标会随阶段演进，更新时请保留历史版本以便回顾。

## 人生主线（长期愿景）
- 建立可跨 AI / 跨设备复用的个人知识与工作档案资产
- 以科技管理与数智化赋能推动本职工作提效，并持续提升计算机与网络能力

## 阶段目标（1年内）
- [ ] 完成并维护 personal-ai-archive，使 ChatGPT / Claude / Gemini / Grok 等都能读取同一份档案
- [ ] 系统学习网络基础与电脑配置，能独立完成常见排障与环境搭建
- [ ] 持续规范公文与正式材料写法，形成可复用的模板与助手协作习惯
- [ ] 推进科信创新工作室与数智化中队相关公开成果的整理与复用（不含内部金额）

## 核心决策原则（AI 排序任务、做权衡时参考）
- 能复用就绝不重复造轮子；优先跨 AI 共享同一份档案
- 正式对外或对内公文材料必须高标准、口径严谨；歧义先问
- 任何不可逆操作（删除、覆盖、对外发布、付费）前先确认
- 公开仓库只写可公开事实；密码、内部金额、隐私联系方式一律不写

## 不做的事 / 边界
- 不在未经确认时提交对外公开内容或代表本人对外发信
- 不将密码、密钥、内部研发费用/利润、未公开电话邮箱写入本仓库
- 不替用户做出未经确认的错误判断；发现判断有误须主动质疑
